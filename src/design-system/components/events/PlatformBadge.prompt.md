Names the source an event came from — emoji + lowercase wordmark in a pastel-tinted pill.

```jsx
<PlatformBadge platform="PARTIFUL" />   // 🎉 partiful, peach tint
```

Mapping is fixed: LUMA `💼 lu.ma` (sky), PARTIFUL `🎉 partiful` (peach), LINKEDIN `💼 linkedin` (sky), EVENTBRITE `🎫 eventbrite` (butter). Platform names stay lowercase — they're wordmarks, not sentences. The tint identifies the source at a glance; don't recolour it to the accent.
